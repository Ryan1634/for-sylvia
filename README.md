# For Sylvia — Cinematic Letter Website

A responsive single-page letter with an opening screen, a reveal transition, subtle heart details, and a mobile-friendly reading layout.

## Preview
Open `index.html` in a browser.

## Publish using GitHub Pages
1. Create a public GitHub repository named `for-sylvia`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish. Copy the URL shown in the Pages section.

The published page is public: anyone with the link may be able to view it. The page does not collect responses or track visitors.
